# CF Compass v4.3.5

这是 CF Compass 在本仓库（`lkrkerry1/cf-compass`）的首个正式发布。代码与 v4.3.4 一致，包含虚拟赛 ±1 秒时间戳估分修复（#45）；本版主要补齐发布流程与迁移说明，不包含功能、数据结构或用户数据变更。

## 发布流程

- 修复发布工作流在仓库没有历史稳定版时无法解析“上一版本”的问题：首个稳定发布会明确跳过上一版升级验证，之后的版本继续执行该验证。
- 发布资产仍为稳定版 9 项：Windows 安装版/便携版、Linux AppImage、Debian 包、macOS Intel/Apple 芯片包，以及 `latest.yml`、Windows `.blockmap`、AppImage `.zsync`。
- 本次安装包未做代码签名（Windows SmartScreen / macOS Gatekeeper 可能提示），macOS 为 ad-hoc 签名。

## 从原仓库迁移

原仓库 `Binah-Dev/cf-compass` 及其 GitHub 账号已被删除，v4.3.4 及更早版本内置的 Windows 更新源随之失效，应用内检查更新会失败。迁移方式：

1. 从本仓库 [Latest Release](https://github.com/lkrkerry1/cf-compass/releases/latest) 手动下载对应平台安装包。
2. 直接覆盖安装即可；应用 ID、安装 GUID 和用户数据目录保持不变，题库缓存、笔记、题单与设置会保留。
3. 建议迁移前先在「数据中心 → 导出全部数据」保存一份备份。
4. 从 v4.3.5 起更新源已切换到 `lkrkerry1/cf-compass`，后续 Windows 安装版可继续在应用内更新；Linux AppImage / `.deb` 与 macOS 包仍需手动替换。

## 校验

- Windows 安装版 / 便携版安装与冷启动检查通过。
- 发布资产经下载回验，`latest.yml` 的版本、文件名、大小与 SHA-512 与安装包一致。
- 首个版本没有可验证的上一稳定版，上一版升级验证按设计跳过并在日志中记录。

## English summary

This is the first formal release of CF Compass in this repository (`lkrkerry1/cf-compass`). The code is identical to v4.3.4, including the virtual-score ±1-second timestamp fix (#45). This release adds release-pipeline and migration documentation only; there are no functional, schema, or user-data changes.

- The release workflow now explicitly skips previous-stable upgrade verification when the repository has no earlier published stable release; later releases keep that verification.
- Migration from the original repository: its update feed no longer exists. Download the new release manually and install over the old version. The app ID, installer GUID, and user-data location are unchanged, so local data is retained. Export a backup from Data Center before migrating.
- Windows installer editions can use in-app updates again starting with v4.3.5; AppImage / `.deb` / macOS packages remain manual updates.
- Packages are unsigned in this release (SmartScreen / Gatekeeper warnings may appear); macOS uses ad-hoc signing.
